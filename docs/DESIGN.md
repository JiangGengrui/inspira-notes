# 设计说明 · 纸与夜

> 灵感便签 Inspira · v2.0 · 2026-11-20

## 1. 产品定位

灵感便签面向「念头比分类更快」的时刻。核心不是任务管理，而是降低记录摩擦，并让旧念头有再次被看见的机会。

四条原则：

| 原则 | 在界面中的落实 |
| --- | --- |
| 记录先于整理 | 速记框常驻首屏，标签从正文自动解析，不要求先选分类 |
| 重逢而非检索 | 日期分组瀑布流 + 随机回顾 + 灵感热力，弱化「文件夹」感 |
| 安静但有触感 | 暖纸／深夜底色、衬线标题、克制的位移与弹簧动效 |
| 本地优先 | 无账号、无网络请求；数据留在本机，备份由用户掌握 |

## 2. 决策记录

| 维度 | 结论 | 说明 |
| --- | --- | --- |
| 视觉方向 | **C · 双主题「纸与夜」** | 日间用暖纸与陶土色，夜间用深墨与薰衣草紫；两套 token 独立调校，而非简单反色 |
| 信息架构 | **A · 侧栏 + 日期分组瀑布流** | 侧栏承担视角与标签导航，主区先速记、再按时间回看 |
| 特色能力 | **多级标签、热力图、随机回顾** | 对应「组织」「节奏」「重逢」三个需求 |
| 基础能力 | 新增、编辑、删除与撤销、置顶、星标、搜索、导入导出 | 保持捕捉闭环完整 |
| 技术形态 | Electron + React + TypeScript | 组件化 UI、类型化数据层、可测试的纯函数 |
| 本期不做 | 全局快捷键、无边框自定义标题栏、安装包分发 | 前者涉及系统级注册与冲突处理，后者涉及签名与跨平台打包；均未纳入本轮范围 |

## 3. 视觉系统

### 3.1 色彩 token

| Token | 纸 · 日间 | 夜 · 深色 | 用途 |
| --- | --- | --- | --- |
| `--bg` | `#f3eee4` | `#0d0e12` | 应用底色 |
| `--surface` | `#fdfaf4` | `#16171e` | 卡片、速记框 |
| `--surface-2` | `#f6f0e5` | `#1c1d26` | 次级表面 |
| `--ink` | `#2b2620` | `#ece8df` | 主文字 |
| `--ink-soft` | `#6f6558` | `#a39c8f` | 辅助文字 |
| `--line` | 棕褐 10% | 白色 8% | 分隔与描边 |
| `--accent` | `#b45c37` 陶土 | `#a08cff` 薰衣草 | 主强调、保存按钮 |
| `--accent-2` | `#b08430` 赭金 | `#5eead4` 青绿 | 次强调、星标 |
| 热力 0–4 | 陶土透明度阶梯 | 紫色透明度阶梯 | 热力图密度 |

主题通过 `document.documentElement.dataset.theme` 与 `color-scheme` 同步切换；`index.html` 在首屏渲染前读取本地偏好或系统主题，避免闪白。

### 3.2 字体与材质

- **标题**：衬线字体栈（Iowan Old Style / Palatino / Songti SC / Noto Serif SC），承担品牌与情绪。
- **正文**：系统无衬线栈（Segoe UI Variable / PingFang SC / Microsoft YaHei），保证中文小字号可读性。
- **材质**：两组低对比径向光晕叠加细颗粒噪点，日间模拟纸张受光，夜间模拟深空微光；卡片使用 22/16/12/8 四级圆角与分层阴影。
- 标签色由路径哈希映射到固定色板，通过 `--tag-hue` 注入，同一标签在两种主题下保持同一色相、不同明度。
- 品牌符号为「圆角陶土方块中的星芒」，favicon 与窗口／任务栏图标共用同一图形。

### 3.3 字体层级

| 层级 | 处理 |
| --- | --- |
| 品牌／问候 | 衬线、20–30px 流式字号、字距略收紧 |
| 分组标题 | 小号衬线 + 计数徽标 + 横向渐隐分隔线 |
| 卡片正文 | 无衬线 13.5px、1.7 行高，标签从正文剥离后展示为彩色 chip |
| 元信息 | 10–11px、低对比、等宽数字语义的相对时间 |

## 4. 布局

- 窗口默认 **1180 × 800**，最小 **960 × 640**，为桌面双栏工作区设计。
- 侧栏基准 **248px**；`≤1280px` 收至 **232px**，`≤980px` 收至 **210px**。主区保持流式宽度。
- 主区自上而下：问候与每日摘要 → 搜索／回顾／主题按钮 → 速记框 → 视角筛选 → 日期分组瀑布流。
- 瀑布流固定 **两列**、列间距 14px。日期分组通常只有 1–3 张卡片，宽屏三列会产生大面积空列，因此不随视口增加列数；更宽的窗口让卡片变宽，保持时间流的整块感。
- `≤1120px` 时压缩搜索宽度、隐藏按钮文字，保留图标与可访问名称；滚动容器禁止横向溢出。
- 组内顺序：置顶优先，其次创建时间倒序；分组顺序固定为今天 → 昨天 → 本周 → 月份（新到旧），置顶不会把「昨天」提到「今天」之前。

## 5. 动效体系

| Token / 场景 | 参数 | 作用 |
| --- | --- | --- |
| `--dur-fast` | 140ms | 悬停、图标态、颜色过渡 |
| `--dur` | 240ms | 常规展开与位移 |
| `--dur-slow` | 420ms | 大面积入场与布局变化 |
| `--ease-out` | `cubic-bezier(0.22, 1, 0.36, 1)` | 进入减速，收束自然 |
| `--ease-spring` | `cubic-bezier(0.34, 1.56, 0.64, 1)` | 轻微回弹，用于强调元素 |
| 卡片入场 | 360ms，按序号 35ms 递增、封顶 240ms | 建立时间流的阅读节奏 |
| 弹窗 | spring（stiffness 320 / damping 30） | 编辑器与回顾的实体感 |
| 回顾切换 | 240ms 交叉淡入上移 | 「换一条」时像抽换一张卡片 |
| 删除 | 160ms 缩小淡出 + 底部提示条 | 快速退场，同时保留撤销入口 |

`prefers-reduced-motion: reduce` 下统一压缩动画与过渡，保留状态反馈但不做位移动效。

## 6. 组件职责

| 组件 | 职责 |
| --- | --- |
| `BrandMark` | 星芒 + 圆角方块的品牌符号，随主题继承颜色 |
| `Sidebar` | 品牌、视角导航与计数、标签树、热力图、导入导出入口 |
| `TagTree` | 递归渲染多级标签，支持折叠、计数、色点与子树筛选 |
| `Heatmap` | 16 周密度网格、活跃天数与连续天数 |
| `Composer` | 自动增高输入、标签实时预览、保存反馈与快捷键 |
| `NoteCard` | 卡片展示、相对时间、置顶／星标、搜索高亮、悬停操作 |
| `EditorDialog` | 模态编辑，保留标签预览与 `Ctrl/⌘ + Enter` 保存 |
| `ReviewDialog` | 随机抽取旧灵感、换一条、日期与标签回顾 |
| `Toast` | 删除撤销与导入结果通知，`aria-live` 播报 |

状态集中在 `NotesProvider`：便签数组、撤销栈、增删改与置顶/星标操作；`App` 负责视角、标签、搜索、弹窗和通知的编排。样式分为 `tokens.css`（设计变量）、`base.css`（重置与全局材质）、`app.css`（组件与响应式布局）。

## 7. 关键交互决策

1. **标签是派生的，不是独立数据**：正文中的 `#标签` 是唯一事实来源，编辑正文即重建标签，避免标签表与文本不同步。
2. **父标签筛选包含子树**：点击 `#设计` 会匹配 `#设计/排版`、`#设计/配色`，符合「先看大方向，再逐步收窄」的心智。
3. **删除不做二次确认**：用 6 秒内联撤销替代阻断式对话框，保护误操作，同时保持删除动作的流畅。
4. **导入是合并，不是恢复出厂**：按 id 去重、导入项覆盖同 id 项，不删除本地独有便签；文件上限 5 MB，读取错误显式提示。
5. **搜索高亮不拼 HTML**：查询与正文按安全的字符串切片渲染，避免 `dangerouslySetInnerHTML`。
6. **回顾优先旧内容**：优先抽取创建超过一天的便签；「换一条」排除当前项，避免原地打转。
7. **快捷键只在应用内生效**：`Ctrl/⌘ + N` 聚焦速记、`Ctrl/⌘ + K` 聚焦搜索、`Ctrl/⌘ + Enter` 保存、`Esc` 关闭弹窗；不注册系统级快捷键。

## 8. 数据模型与安全

```ts
interface Note {
  id: string
  content: string        // 含内联 #标签 的原文
  tags: string[]         // 从 content 派生
  pinned: boolean
  starred: boolean
  createdAt: number
  updatedAt: number
}
```

- 持久化键：`inspira.notes.v1`（`{ version, notes }`）、`inspira.theme`；写入按 200ms 防抖。
- 首次启动无数据键时生成 7 条示例便签；数据损坏时回退为空列表，不阻塞启动。
- 主进程启用 `contextIsolation`、关闭 `nodeIntegration`，仅通过 preload 暴露 `platform / exportJson / importJson`；外链只允许 `https` 并交给系统浏览器。
- 应用不发起网络请求，导出与导入均使用系统文件对话框。

## 9. 可访问性

- 导航、筛选、搜索、主题按钮、热力图均有语义标签；弹窗使用 `role="dialog"`、`aria-modal` 与标题关联。
- 删除提示条使用 `role="status"` + `aria-live="polite"`，撤销按钮可键盘触达。
- 全站保留 `:focus-visible` 焦点环；动效支持 `prefers-reduced-motion` 降级。
- 本轮未执行正式的对比度审计与屏幕阅读器全流程测试，作为后续质量项。
